# 幸存者协议 · Survivor Protocol

《一个人做一款游戏》系列文章末尾的**可玩成果样例**：俯视角射击 + 波次生存的最小可玩原型。
纯前端（HTML5 Canvas + 原生 JS），**无依赖、无素材、无网络请求**——双击 `index.html` 就能玩。

---

## 运行

- 双击 `index.html`（推荐，离线可玩）；
- 或 `python -m http.server 8000`，访问 `http://localhost:8000`。

**操作（电脑）**：`WASD`（或方向键）移动 · 鼠标瞄准 · `鼠标左键`射击（0.15s 冷却）· `Esc` 暂停 · `M` 静音 · `R` 重开。

**左上角 ⚙ 设置**：可以**手动开关「手机模式」**（触屏摇杆 + 点哪打哪）和音效。标题界面和游戏里都有这个齿轮；手机模式默认跟着设备走（触屏设备自动开），开关结果记在 `localStorage`（键名 `sp-mobile-mode`），下次打开还是你上次的选择；地址栏的 `?touch=1` / `?touch=0` 可以强制指定（给自动化测试用）。**设置面板打开时世界冻结**，不会在菜单里被打死；点面板外面、点「关闭」或按 `Esc` 都能关。

**操作（手机 / 平板）**：
- **左手**：屏幕左下方按住拖动 = 虚拟摇杆（原点跟着按下点走，推一半就是半速，模拟量）；
- **右手**：屏幕**其他任意位置**按住 = **点哪打哪**——枪口指向按下的那个点，按住不放就持续开火，手指移动瞄准点跟着移动；
- 右上角一排三个按钮：`⏸ 暂停` / `🔊 静音` / `⛶ 全屏`（横屏手机上建议先点全屏）；
- 标题、升级三选一、死亡 / 胜利结算界面都可以直接点；
- **只做横屏**：手机竖着拿会看到中间一条 16:9 的缝，请横过来玩（点右上角 `⛶` 进全屏，安卓上会顺手尝试锁横屏）；
- 触屏层只在手机模式打开时出现；电脑上默认关闭（触屏设备默认打开），随时可在左上角 ⚙ 里改，改完立刻生效。

**目标**：活过 10 波（第 10 波有首领），或看看自己能撑多久。

## 开发数据（写文章可以直接用）

- 代码量：`game.js` 1763 行 / 71 KB（其中手机模式 + 设置面板约 +410 行），`index.html` 34 行。
- 从需求大纲到可玩原型：一次成型的工程骨架 + 两轮修改；验收用无头 Chrome 自动跑（见下）。
- 自动化验收覆盖：载入无报错 → 开始 → 模拟键鼠（移动 + 连续射击）→ 敌人生成 → 加经验进升级界面 → 选强化 → 跳第 10 波 + 首领 → 死亡 → 胜利 → 暂停。**控制台 0 报错**。
- 手机端验收（CDP `Input.dispatchTouchEvent` 真触摸事件，不是改代码调函数）：单指开火 1→4 发、松手后不再增长；摇杆向右推 0.7 秒位移 +202px、向上 0.6 秒 -110px；瞄准角实测 -0.346 rad vs 理论 -0.325 rad（差 1.2°，是采样间隔里玩家还在移动）；暂停/静音按钮可点且**点按钮不会误开火**；像素采样确认摇杆环（亮度 120 vs 背景 17）、摇杆头（159）、准星（像素 RGB 231,191,95）都真的画出来了。电脑端回归：鼠标点一下开局、按住开火、`W` 前移、**触屏 UI 一个像素都不画**。
- 设置面板验收：点左上角 ⚙ → 面板打开、`elapsed` 与敌人数在 900ms 内**完全不变**（世界冻结）；开关手机模式 → `__GAME.mobile` 翻转、`localStorage['sp-mobile-mode']` 同步写 `"1"/"0"`、摇杆提示区亮度 23（关，等同背景）↔ 116（开）；关闭后鼠标照样能开枪（3 发）。

### 踩过的坑（真实记录，可当写作素材）

1. **升级界面吞掉波次间歇**：升级是在击杀瞬间触发的，如果那一下发生在"波间暂停 3 秒"里，选完强化会直接回到 `playing`，3 秒喘息就没了。修法：打开升级界面时记住"进来之前是哪个状态"，选完按原状态返回。
2. **间歇期间免伤**：一开始把"造成伤害"限制在 `playing` 状态，结果波间暂停时敌人贴脸却不掉血，读起来像 bug。改成 `playing || break` 都算。
3. **敌人撞玩家后不该掉经验**：撞死了自己却给玩家经验，会让"躲"变成一种收益；按大纲 3.5 只扣血、不给经验。
4. **无头浏览器截图**：用 CDP `Page.captureScreenshot` 抓关键状态出图，比手动截屏稳定，也方便以后改版重新生成配图。
5. **竖屏最后没做**：一开始想加「请把手机横过来」的覆盖层，第一版判断用画布宽高比——可画布本身永远是 16:9（等比缩放），那个条件永远不成立。正确的判据是**窗口**的 `innerWidth/innerHeight`。改对之后结论变成了"这个游戏根本只适合横屏"，所以干脆删掉整块，只留全屏按钮 + 安卓锁横屏。**删代码也是设计决策**。
6. **触摸不能写死坐标**：画布是等比缩放在窗口中间（还有黑边），所以"逻辑坐标 150,360"和"手指的屏幕坐标 150,360"是两个点。触屏要先 `getBoundingClientRect()` 再换算，不然摇杆命中区和实际画的位置会错开一大截。
7. **按钮不能误开火**：触摸的命中顺序必须是「设置面板 → 齿轮 → 界面态 → 顶栏按钮 → 摇杆区 → 瞄准」，否则点在暂停按钮上会同时开一枪（验收里专门断言了 `firedOnButtonTap === false`）。
8. **设置面板必须冻结世界**：第一版忘了冻结，在面板里调开关时怪照常贴脸，玩家一只手在菜单上一只手没法躲，纯送头。改成 `if (S.settings) { /* 什么都不更新 */ }`，敌人的位置和经验值都停在打开的那一帧（验收里断言了 900ms 后 `elapsed` 和敌人数都不变）。

## 已知限制

- 没有存档 / 排行榜（一个原型不需要）；最高分只记"历史最长存活"，存在 `localStorage`。
- **只支持横屏**：画布是 16:9 的，竖着拿只有中间一条缝（没有竖屏适配，也不打算做）；横屏 + 触屏操作已完整支持。
- 触屏只有一根"瞄准手指"：同时按两个地方开火，以第一根为准；也没有自适应灵敏度 / 摇杆死区调节（死区固定 6px）。
- 敌人追踪是直线，不做避障（大纲里明确是简化版）。
- 数值是照着大纲抄的，没有做过平衡性调参——想调就改 `game.js` 顶部的 `ENEMY` / `WAVE` 两张表。
- 移动手感在 `game.js` 顶部的 `MOVE`：`accel`（越大起步越干脆）、`damp`（越大松手停得越快，越小越滑）、`trailSpeed`（多少速度开始出现拖影）。
- 回血包的全部参数集中在 `game.js` 顶部的 `HEALPACK`（掉率 `chance` / 间隔 `every` / 回血量 `heal` / 同屏上限 `max` / 存活 `life`），想改 30% 就是改那个数字。
- 世界大小 `WORLD`（3200×2400）和障碍物生成规则 `makeObstacles()`（数量 `34`、尺寸、出生点留空 320px、互不重叠）都在 `game.js` 里，想改地图规模只动这两处。

## 给读者的改造建议

- **换美术**：把 `drawEnemy` 里的三角/方块/圆换成精灵图，逻辑一行不用动。
- **加武器**：现在只有一种子弹；把 `shoot()` 里的子弹参数（速度/伤害/穿透/冷却）做成武器表，就能加霰弹、激光、追踪弹。
- **加 Boss 技能**：首领目前只是"血厚"，可以在 `updateEnemies` 里按血量阶段触发冲刺、召唤小兵。
- **接排行榜**：把 `localStorage` 换成一个小接口，就是联网排行。
- **搬去 Godot**：数据表（`ENEMY` / `WAVE` / `UPGRADE`）可以原样抄成 GDScript 常量，`game.js` 的各个 `update*` 函数一一对应到 `_physics_process`。
