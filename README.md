# 幸存者协议 · Survivor Protocol

《一个人做一款游戏》系列文章末尾的**可玩成果样例**：俯视角射击 + 波次生存的最小可玩原型。
纯前端（HTML5 Canvas + 原生 JS），**无依赖、无素材、无网络请求**——双击 `index.html` 就能玩。

---

## 运行

- 双击 `index.html`（推荐，离线可玩）；
- 或 `python -m http.server 8000`，访问 `http://localhost:8000`。

**操作**：`WASD`（或方向键）移动 · 鼠标瞄准 · `鼠标左键`射击（0.15s 冷却）· `Esc` 暂停 · `M` 静音 · `R` 重开。

**目标**：活过 10 波（第 10 波有首领），或看看自己能撑多久。

## 开发数据（写文章可以直接用）

- 代码量：`game.js` 785 行 / 30.5 KB，`index.html` 25 行，合计约 **810 行**。
- 从需求大纲到可玩原型：一次成型的工程骨架 + 两轮修改；验收用无头 Chrome 自动跑（见下）。
- 自动化验收覆盖：载入无报错 → 开始 → 模拟键鼠（移动 + 连续射击）→ 敌人生成 → 加经验进升级界面 → 选强化 → 跳第 10 波 + 首领 → 死亡 → 胜利 → 暂停。**控制台 0 报错**。

### 踩过的坑（真实记录，可当写作素材）

1. **升级界面吞掉波次间歇**：升级是在击杀瞬间触发的，如果那一下发生在"波间暂停 3 秒"里，选完强化会直接回到 `playing`，3 秒喘息就没了。修法：打开升级界面时记住"进来之前是哪个状态"，选完按原状态返回。
2. **间歇期间免伤**：一开始把"造成伤害"限制在 `playing` 状态，结果波间暂停时敌人贴脸却不掉血，读起来像 bug。改成 `playing || break` 都算。
3. **敌人撞玩家后不该掉经验**：撞死了自己却给玩家经验，会让"躲"变成一种收益；按大纲 3.5 只扣血、不给经验。
4. **无头浏览器截图**：用 CDP `Page.captureScreenshot` 抓关键状态出图，比手动截屏稳定，也方便以后改版重新生成配图。

## 已知限制

- 没有存档 / 排行榜（一个原型不需要）；最高分只记"历史最长存活"，存在 `localStorage`。
- 手机竖屏不友好（画布等比缩小），横屏体验更好；操作是按键鼠设计的。
- 敌人追踪是直线，不做避障（大纲里明确是简化版）。
- 数值是照着大纲抄的，没有做过平衡性调参——想调就改 `game.js` 顶部的 `ENEMY` / `WAVE` 两张表。
- 移动手感在 `game.js` 顶部的 `MOVE`：`accel`（越大起步越干脆）、`damp`（越大松手停得越快，越小越滑）、`trailSpeed`（多少速度开始出现拖影）。
- 回血包的全部参数集中在 `game.js` 顶部的 `HEALPACK`（掉率 `chance` / 间隔 `every` / 回血量 `heal` / 同屏上限 `max` / 存活 `life`），想改 30% 就是改那个数字。
- 世界大小 `WORLD`（3200×2400）和障碍物生成规则 `makeObstacles()`（数量 `34`、尺寸、出生点留空 320px、互不重叠）都在 `game.js` 里，想改地图规模只动这两处。

## 给读者的改造建议

- **换美术**：把 `drawEnemy` 里的三角/方块/圆换成精灵图，逻辑一行不用动。
- **加武器**：现在只有一种子弹；把 `shoot()` 里的子弹参数（速度/伤害/穿透/冷却）做成武器表，就能加霰弹、激光、追踪弹。
- **加 Boss 技能**：首领目前只是"血厚"，可以在 `updateEnemies` 里按血量阶段触发冲刺、召唤小兵。
- **接排行榜**：把 `localStorage` 换成一个小接口，就是联网排行。
- **搬去 Godot**：数据表（`ENEMY` / `WAVE` / `UPGRADE`）可以原样抄成 GDScript 常量，`game.js` 的各个 `update*` 函数一一对应到 `_physics_process`。
